# Transciphering using a One-Time Pad

This document explains how to use the one-time pad functionality to encrypt user inputs.

Transciphering is the process of encrypting an input with a symmetric cipher, encrypting the symmetric key under LWE, and then running the cipher's decryption algorithm homomorphically. The result is the same input encrypted under LWE, ready for FHE computations.
Using the [encrypted PRF](encrypted-prf.md), the key can be generated directly in FHE, then decrypted (for example by a KMS) and sent to the user.

The main advantages are that the inputs are smaller (most symmetric ciphers add no size overhead to the ciphertext), and that the end user never manipulates LWE ciphertexts. This removes the need for zero-knowledge proofs, since the user cannot submit a malformed LWE ciphertext in this setup.

The one-time pad is a simple cipher where the key (or pad) is at least as long as the value being sent. At encryption time, the user XORs the input with the pad, and the server XORs it again with the encrypted pad. This is secure as long as the pad bytes are random and never reused for two different inputs.

{% hint style="warning" %}
The bits of a pad **must never** be used more than once. If the same pad bits are used to encrypt two different values, XORing the two ciphertexts cancels the pad and leaks the XOR of the two values.
Pads are generated deterministically from their seed, so this also means that the same seed **must never** be used to generate the pads of two different inputs.
{% endhint %}

## Usage example

Here is an example of the full flow, where the pad is generated by the server, decrypted, then used by the client to encrypt some values that are transciphered by the server:

```rust
use tfhe::prelude::*;
use tfhe::shortint::parameters::{
    NOISE_SQUASHING_PARAM_MESSAGE_2_CARRY_2_KS_PBS_TUNIFORM_2M128,
    PARAM_MESSAGE_2_CARRY_2_KS_PBS_TUNIFORM_2M128, TranscipheringParameters,
};
use tfhe::transciphering::OneTimePadPlainState;
use tfhe::{
    generate_keys, set_server_key, ConfigBuilder, FheBool, FheInt8, FheUint64, HlTranscipherer,
    OneTimePadFheSecretMask, Seed, StreamCiphertextList, TranscipherSession,
};

pub fn main() {
    // Configure computations enabling transciphering, and noise squashing to decrypt the pad
    let config =
        ConfigBuilder::with_custom_parameters(PARAM_MESSAGE_2_CARRY_2_KS_PBS_TUNIFORM_2M128)
            .enable_noise_squashing(NOISE_SQUASHING_PARAM_MESSAGE_2_CARRY_2_KS_PBS_TUNIFORM_2M128)
            .enable_transciphering(TranscipheringParameters::SameAsCompute)
            .build();
    let (client_key, server_key) = generate_keys(config);

    set_server_key(server_key);

    // Server: generate an encrypted pad, large enough for a u64, a bool and an i8
    // Each value starts on a byte boundary, so the bool takes 8 bits of the pad
    let n_bits = 64 + 8 + 8;
    // DANGER: Static Seed(0) given as an example only
    // use proper seeding strategy depending on use case
    let fhe_pad = OneTimePadFheSecretMask::new_random(Seed(0), n_bits).unwrap();

    // Decrypt the pad, for example using a KMS, and send it to the client
    // We don't perform the threshold decryption here, but the noise is squashed as it would be
    // before such a decryption
    let squashed_pad = fhe_pad.squash_noise().unwrap();
    let plain_pad = squashed_pad.decrypt(&client_key);

    // Client: encrypt the values with the pad
    let clear_a: u64 = 1234567;
    let clear_b = true;
    let clear_c: i8 = -42;

    let list = StreamCiphertextList::builder()
        .push(clear_a)
        .push(clear_b)
        .push(clear_c)
        .build(&mut OneTimePadPlainState::new(plain_pad))
        .unwrap();

    // Server: transcipher the values using the encrypted pad
    let mut session = TranscipherSession::one_time_pad(fhe_pad).unwrap();
    let expander = session.transcipher_list(&list).unwrap();

    let a: FheUint64 = expander.get(0).unwrap().unwrap();
    let b: FheBool = expander.get(1).unwrap().unwrap();
    let c: FheInt8 = expander.get(2).unwrap().unwrap();

    // The transciphered values are regular ciphertexts, ready for FHE computations
    let dec_a: u64 = a.decrypt(&client_key);
    let dec_b: bool = b.decrypt(&client_key);
    let dec_c: i8 = c.decrypt(&client_key);
    assert_eq!((dec_a, dec_b, dec_c), (clear_a, clear_b, clear_c));
}
```
